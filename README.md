# To-Do List

A full-stack to-do list app. I wrote the backend while learning Java and Spring Boot, and created the frontend with [Claude Code](https://claude.com/claude-code).

- **Backend:** Java, Spring Boot, Spring Data JPA (Hibernate), MySQL
- **API:** REST endpoints to create, read, update, toggle and delete todos, with optional filtering on completed status
- **Validation:** Bean Validation on incoming requests, with field-level error messages returned as `ProblemDetail` responses
- **Frontend:** Plain HTML, CSS and JavaScript (created with Claude Code), served by Spring Boot from `static/`
